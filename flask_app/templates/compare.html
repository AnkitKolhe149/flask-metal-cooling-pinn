🧠 What Makes PINN Different?

DNN Loss

L_DNN = MSE(θ_pred, θ_actual)

The DNN only sees labelled data. It has no notion of the physical law governing cooling. Given sparse or noisy data, it may predict thermodynamically impossible trajectories (e.g. temperature rising during quenching).

PINN Loss

L_PINN = L_data + λ·L_physics + λᵢc·L_IC
L_physics = ‖dθ/dτ + β·θ‖²
L_IC = ‖θ(τ=0) − 1‖²

The PINN adds two extra loss terms: a physics residual enforcing Newton's cooling equation, and an initial-condition loss ensuring the model starts at θ=1 (full temperature) at τ=0. The cooling coefficient β is learned jointly with the network weights.

🔢 Why Tanh in PINN?

The PINN uses Tanh activations rather than ReLU because:

  • The physics loss requires computing dθ/dτ — a derivative w.r.t. the network input
  • Tanh is infinitely differentiable; ReLU has zero derivative almost everywhere
  • Tanh maps inputs to (−1,1), matching the bounded nature of θ
  • Smoother gradients prevent the physics loss from producing NaN updates

The DNN uses ReLU — standard for regression tasks, computationally cheaper, but incompatible with derivative-based physics constraints.
